## Sobre

Sou Gustavo Carvalho, estudante de Desenvolvimento de Software Multiplataforma (DSM) na Fatec Jacareí e desenvolvedor PHP. Este repositório reúne meu portfólio acadêmico, com os projetos desenvolvidos ao longo do curso — do 1º ao 6º semestre — abrangendo desde plataformas web até aplicativos móveis e sistemas com inteligência artificial.

Ao longo desses projetos atuei em diferentes papéis: como **Scrum Master** (também programando) nos três primeiros e como **Desenvolvedor** nos demais. As tecnologias incluem PHP, JavaScript/TypeScript, React, React Native, Node.js, MySQL, PostgreSQL e MongoDB.
